# MarkRead v1.2.1 — Candidate Changelog

30/10/2026 · Bản chuẩn bị phát hành APK trực tiếp, **chưa gắn tag hoặc đưa lên GitHub Releases**.

## Giao diện đọc

- Gộp toolbar thành một hàng: menu, tên file, Previous, Next, Search, Save, Settings. Bỏ nút ba chấm và hàng nút thứ hai.
- Thu icon trên header xuống20px, giữ vùng chạm48×48CSSpx. Tên file dài dùng ellipsis và giữ accessible name đầy đủ; ở điện thoại320px phần tên hiển thị rất ngắn.
- Bỏ entry point “chọn khối để sửa” trong Reader. Source Editor thông thường vẫn truy cập qua Cài đặt → Đọc & chỉnh sửa → Chế độ tài liệu → Nguồn Markdown.
- Đồng bộ visual state khi nhấn Save; giữ focus, reduced motion,12theme, custom CSS và chức năng hiện có.

## Phát hành và tương thích

- Cập nhật versionName **1.2.1**, versionCode **121**; giữ applicationId `vn.markread.local`, minSdk26/targetSdk35, quyền Android và signing certificate release cũ.
- Không đổi logic Markdown, file/SAF, Search/Replace, Undo/Redo, JavaScript bridge, dependencies, analytics hoặc truy cập mạng.
- APK candidate được kiểm cài đè bản signed v1.2.0 trên AVD riêng mà không xóa dữ liệu; Settings/CSS/SAF và các file đã lưu được giữ. Hãy lưu bản sửa còn trong RAM trước khi cập nhật.

Xem [báo cáo build](V1.2.1_REPORT.md) và [kiểm thử nâng cấp](V1.2.1_UPDATE_VALIDATION.md) trước khi quyết định phát hành.
